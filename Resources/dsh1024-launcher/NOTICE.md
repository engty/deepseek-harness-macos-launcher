# dsh1024 macOS Launcher adapter

Upstream: dsh1024 0.5.0, https://github.com/imsai-sh/awesome-deepseek-harness-plugins/tree/main/packages/dsh1024

License: MIT; the original license is included in LICENSE.

This directory contains reviewed replacements for selected upstream files, not a separate store or registry. Changes: native transactional installation handoff, disabled self-updates, and installation error reporting. Upgrade the pinned upstream version and these files together after testing. The launcher rejects unknown upstream versions instead of overwriting them.
