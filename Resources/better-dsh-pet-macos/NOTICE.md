# better-dsh-pet macOS adapter

This directory contains the macOS runtime adapter used when packaging
`better-dsh-pet@0.3.5` into DeepSeek Harness. The DSH bundle and animation
assets are fetched from the upstream npm package during Runtime assembly; this
directory only carries the platform-specific adapter files.

- Upstream project: <https://github.com/ysppwn721/better-dsh-pet>
- macOS adapter reference: <https://github.com/williamhadeslee/better-dsh-pet-macos>
- Reference commit: `7eeb2fcea9b4503295604508ccaf6bc8f19be64b`
- Upstream package version: `0.3.5`

The upstream package is MIT-licensed code, but its animation/source assets may
have additional non-commercial and attribution requirements. Keep the upstream
README and license alongside any distributed Runtime and verify those terms
before commercial redistribution.
